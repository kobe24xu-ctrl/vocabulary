# LexiClass · 词间课堂

面向国际预科班级的场景词汇听写应用。教师管理 UNSW 新南预科、NCUK 国际预科、UOW 伍伦贡预科的多个班级；由唯一的 `master` 管理账户统一维护学生名单、课程词库及考试并发布链接，学生通过自己的网页账号完成测试、查看历次成绩并反复复习错题。

采用网页应用：学生在 Windows、macOS 浏览器中打开老师分享的考试链接即可使用，无需安装客户端、Node.js 或数据库。教师同样可直接使用网页端，也可选择安装 PWA 桌面快捷方式；不提供原生 `.exe` / `.dmg` 安装包。

界面截图：[教师工作台](docs/screenshots/teacher.png) · [学生网页登录](docs/screenshots/student-login.png) · [考试链接入口](docs/screenshots/exam-entry.png) · [学生学习空间](docs/screenshots/student.png) · [场景听写](docs/screenshots/dictation.png)。截图均使用虚构示例数据。

## 先试用，无需配置服务器

可使用 `npm run demo:build` 生成单文件 `dist/lexiclass-demo.html`，本次聊天也提供已生成的试用文件。该文件内置网页样式、示例词库与本机演示数据，不依赖后端、npm、CDN 或外部 API。下载后可用普通桌面浏览器打开，先从教师工作台发布任务，再点「体验学生端」切换示例学生，答题后回到教师端查看成绩。

**这是本机交互演示，不是 GPT 托管或在线网站。** 记录仅保存在当前浏览器，不能跨电脑共享，不适用于正式考试；请勿录入真实学生信息或真实密码。「重置示例」只清理此演示的数据。真实网站继续使用服务器上的账号、SQLite 数据库和权限控制，演示适配器不会被正式应用加载。

开发者可用 `npm run test:demo` 验证单文件的发布、答题、刷新保存、评分和错题复习。当前托管浏览器禁止 `file://` 导航，因此该检查将生成文件的原文从内存提供给浏览器，关闭网络完成交互验证；真实 Windows/Mac 上双击本地文件打开仍需用户验收。

## 本地运行正式服务

需要 **Node.js 24 或更高版本**。应用只使用 Node.js 内置模块，无第三方运行时依赖。

```bash
cd /workspace/vocabulary
npm ci --ignore-scripts
npm start
```

服务默认绑定本机 `127.0.0.1` 的 3000 端口。打开该地址即可进入。点击「体验教师与学生演示」可创建独立的演示空间，示例姓名、班级与成绩均为虚构，和正式教师数据隔离。

正式使用时，在登录页点击「首次使用 · 设置 Master 账户」。在服务器上私下打开首次启动生成的 `data/setup-key`，输入设置密钥、自设的 Master 密码和首个班级名称。管理账号固定为 `master`，不填写教师姓名或邮箱。不要把该密钥或个人学习入口发到公开群，也不要把它们提交到 Git。初始化后此密钥不能再创建账号。

如需自定义配置，将 `.env.example` 复制为 `.env` 后修改。`npm start` / `npm run dev` 自动加载 `.env`；环境变量也可以由服务管理器注入。

## 教师使用流程

1. **创建班级**：选择课程项目，分别建立实际教学班。`master` 统一管理三个项目下的全部班级、学生、课程内容和考试。
2. **添加学生**：按班级批量粘贴学生姓名，每行一位。同班同名学生请添加学号以便区分。
3. **开通学生网页账号**：下载个人开通入口 CSV，分别私下交给学生。入口凭证保存在链接片段中，不发送给服务器访问日志。学生首次填写老师登记的姓名，用学习码设置唯一账号和密码，班级和项目自动关联；开通成功后该学习码立即失效。没有个人链接时，也可在登录页点击「首次使用」手动输入学习码。
4. **维护词库**：按项目、科目录入英文词、中文释义、英文场景句、对应中文场景和可接受的其他中文答案，也可批量导入 UTF-8 CSV，每批最多 300 条。
5. **发布考试**：先选择班级，自动显示该班已配置的科目和学生名单；默认全选全部学生，可逐个取消勾选，也可全选或取消全选。课程项目由班级自动关联，无需手动选择。选择科目、词汇、题型、起止时间和答题时长。可按相同本地时间一次排好连续 1–30 天的任务，每天单独计分。
6. **分享考试链接**：发布成功后复制考试链接，发到班级群；也可从任务卡片的「考试链接」按钮再次获取。学生打开后登录自己的账号，直接进入这场考试的说明页，点击开始才计时。尚未开放显示等待，已交卷显示本人结果。链接转发不会扩大原先的班级或个人分配范围。
7. **查看班级成绩**：按项目、班级、科目、任务和姓名筛选，查看每位学生的成绩、提交状态、时间和逐题答案；可导出 CSV。未开始、进行中、未提交和已提交分别显示。

学生不会看到项目选择器、班级选择器或其他同学的名单和成绩。所属项目和班级由老师登记。学生账号跨浏览器、跨设备使用，历次成绩和错题归到同一个学生 ID，关闭网页不会丢失服务端记录。

忘记密码时，老师在学生名单中重置个人开通入口。旧密码、旧学习码和已有会话失效，学生用新学习码重新设置账号密码，原来的成绩、答题和错题保留。已有版本的学生记录通过数据库的增量迁移保留；老师为未开通账号的学生分发或重置学习码即可，不要重复创建学生。

## 题型、计时与错题

- **英译中**：在英文题干内高亮目标词汇，填写中文释义。
- **中译英**：在中文场景内高亮目标词义，填写英文词汇；学生答题接口不会返回英文参考答案。
- **双向翻译**：交替安排以上两种题型。
- **场景选择题**：根据题干选择词义，选项顺序随机；同科目需有至少四个不同释义可供出题。
- **朗读**：英译中和选择题可点击本地系统语音朗读英文场景，仅使用已安装的离线英文语音，不回退到在线服务；未安装时提示老师先配置语音包。

开始后计时不可暂停。个人答题截止取“开始时间 + 答题时长”和任务截止时间的较早者。刷新或重新登录可继续同一份答题记录，不会重新计时。答案在输入后自动保存，界面显示服务器保存状态。

超时时，服务端以**截止前成功保存的答案**评分，未作答计错；超时后补传的答案不会改变成绩。即使关闭页面，服务端也会处理已开始答题的超时提交。尚未开始的任务到期显示未提交，不虚构成绩。提交之后不可修改。

评分为每题等权、折算百分制。匹配时忽略英文大小写、空格及标点，支持老师录入的中文别名；**没有使用 AI 或语义模糊判分**，其他合理译法需提前列入可接受答案。系统不会自动把拼错的词当成正确答案。

答错或空白的词汇自动进入个人错题本，同词同方向不会重复建条目；后续答错会累计错误次数并重新安排复习。先即时巩固，第一次答对后 1 天复习、第二次答对后 3 天复习，连续答对 3 次标记已掌握；答错后 10 分钟可重试。客户端不能通过连续刷新绕过复习间隔。

任务按指定时间开放，学生应用每 30 秒同步一次。桌面提醒须学生授权，并保持应用运行；目前没有应用关闭时的 Web Push、短信或邮件提醒。

## 关闭输入自动纠错

答题框明确设置：

```html
autocomplete="off" autocorrect="off" autocapitalize="off" spellcheck="false"
```

同时请求常见语法扩展不要启用，并在浏览器可取消的英文 `insertReplacementText` 输入事件中阻止自动替换。正常的中文输入法组合输入不被屏蔽。

**这些设置不能强制控制操作系统、第三方输入法或所有浏览器扩展。** 正式课堂请老师统一检查：

- **Windows 11**：设置 → 时间和语言 → 输入，关闭「自动更正拼写错误的单词」及物理键盘文本建议（具体名称随系统语言与版本而异）。Windows 10 对应入口通常在设置 → 设备 → 输入。
- **macOS**：系统设置 → 键盘 → 文本输入 → 编辑，关闭「自动纠正拼写」和行内预测文本；检查英文输入源的文本替换设置。
- **搜狗、QQ 等输入法**：关闭其英文自动纠错、联想补全、自动替换；答英文题建议切换系统英文键盘。
- **浏览器扩展**：在课堂应用中禁用拼写/语法自动替换扩展，或由学校设备管理统一配置。

这是一款课堂练习工具，目前没有锁屏、考试监控或禁止切换其他应用的功能。

## 网页访问与教师可选安装

先将服务部署到学生可访问的 HTTPS 域名。老师和学生使用同一个站点，无需在学生电脑安装任何客户端。

- **学生**：直接在 Edge、Safari 或 Chrome 中打开考试链接，登录自己的账号后参加考试；平时打开站点即可查看测试、历史成绩和错题本。
- **教师**：直接使用网页管理所有班级；若希望有独立桌面窗口，可在 Windows Edge/Chrome 中安装应用，或在支持的 macOS Safari 中选择「添加到程序坞」。安装完全可选，学生端没有安装操作入口。
- 页面资源由本站提供，不依赖外部字体或 CDN。测试、保存、提交和复习需要联网。
- PWA 缓存应用外壳，不缓存名单、成绩、登录响应或提交请求。普通局域网 HTTP 可用于开发网页访问；正式课堂使用 HTTPS，桌面通知与教师可选安装也通常需要 HTTPS。

学生网页关闭时不会收到实时推送；预约任务会按服务器时间开放。已开始的考试即使关页也不会暂停服务端计时。不要给每台学生电脑独立启动服务器，否则无法集中汇总成绩。

## 正式部署

**中国大陆课堂使用优先采用[国内云服务器部署方案](docs/mainland-deployment.md)**。页面、接口、字体和图标均由学校服务器提供；学生不依赖 GitHub、Google、npm 或境外 CDN。朗读仅使用本地英文语音包。文档附 Nginx、systemd 和自有证书配置，生产部署无需下载 Docker 镜像或 npm 依赖。实际免 VPN 连通性仍需在部署后的中国大陆学校网络验收。

可以直接运行 Node.js，并由学校的 HTTPS 反向代理转发；也提供 Docker Compose + Caddy 配置：

1. 准备服务器与真实域名，将域名 DNS 指向服务器，开放 80/443 端口。
2. 在部署机器的 `.env` 中设置 `APP_DOMAIN=你的真实域名`。
3. 运行 `docker compose up -d --build`。Caddy 会申请证书并转发到应用。
4. 从应用容器的 `/app/data/setup-key` 私下获取首次设置密钥，访问域名创建正式教师账号。
5. 录入实际课程词汇和班级，再分发学生入口。

Compose 默认关闭演示，数据库保存在 `lexiclass_data` 持久卷；应用容器以非 root 用户运行。若自行部署 Node.js，至少设置：

```text
NODE_ENV=production
ALLOW_DEMO=false
HOST=127.0.0.1
PORT=3000
PUBLIC_ORIGIN=https://你的真实域名
DATA_DIR=/受保护的持久数据目录
```

`PUBLIC_ORIGIN` 必须与访问域名一致且无末尾斜杠，用于来源检查及 HTTPS 会话 Cookie。域名配置好之后重新生成学生入口，避免把本地开发地址分发给学生。

正式管理账号只有一个，登录名固定为 `master`，由学校管理者自己设置并保管密码，统一管理所有项目与班级。没有按个人教师注册或分配资料的流程。已有版本建立的教师账号直接使用 `master` 加原密码登录，学生、班级、词库、试卷、成绩和错题保留原记录。暂不提供邮件找回密码或学校 SSO。Cloudflare 发布和国内服务器部署说明分别见对应文档；真实 Windows/macOS 浏览器需在目标机器上验收。

## 数据、备份与验证

班级、学生、词库、任务快照、答题记录、错题和会话保存在 `data/lexiclass.sqlite`。密码使用 scrypt 加盐哈希；学习码和会话令牌仅保存哈希。数据目录、备份与入口 CSV 含有个人记录，应由老师或学校管理员保管。不要上传 `data/`。

在线一致性备份：

```bash
npm run backup -- /受保护的备份目录/lexiclass-2026-10-18.sqlite
```

恢复时先停止应用，用备份替换数据目录内的数据库，清理旧的 `lexiclass.sqlite-wal` / `lexiclass.sqlite-shm`，保留访问权限后再启动。请先确认备份可读，且不要覆盖唯一一份现有数据。当前架构采用单 Node.js 实例与 SQLite，适合班级和小型教学中心的初期使用；尚未做大规模并发压测。

```bash
npm test
```

测试使用临时数据库，覆盖身份和班级隔离、定向发布、题目答案保密、自动保存和恢复、评分、错题复习、服务端截止与超时、入口失效、演示隔离、进程重启持久化及输入框设置。`npm run dev` 开启开发热重启。没有需要单独启动的数据库服务、付费 API 或外部凭据。

浏览器交互验证使用开发依赖 Playwright，独立启动临时服务与数据库，结束后清理；无需使用正式学生数据：

```bash
npx playwright install chromium
npm run test:browser
```

若开发机已有 Chromium，可通过 `BROWSER_PATH` 指定其路径；仅在需要的容器环境中设置 `BROWSER_NO_SANDBOX=1`。交互检查覆盖建班、批量学生、学生账号开通、考试链接、跨设备登录、连续定向任务、答题框纠错设置与可取消自动替换、刷新恢复、评分、错题复习和窄屏布局。实际执行验证的平台为 Linux Chromium，尚未在真实 Windows/macOS 设备上完成浏览器及教师可选安装验收。

## 词库来源

## 反馈表名单与姓名账号

管理员可从包含五张「总表」的反馈 Excel 导入实际班级、学生及课程。仅读取名单与「课程内容」列，不导入课堂表现、建议、作业成绩，也不把生成的个人报告再算作学生。导入脚本位于 `scripts/import-feedback.py`，需要 Python 3 和 `openpyxl==3.1.5`。

```sh
python scripts/import-feedback.py /私有路径/反馈表.xlsx
# 正式导入时使用 --apply --password-stdin，初始密码从标准输入提供。
```

仅在 Cloudflare 已有正确的 master 和五个班级框架、已执行数据库迁移时使用导入。脚本预先检查班级匹配、全局姓名账号冲突，再为新学生分别加盐计算密码哈希；重复导入保留已开通账号的密码和历史 ID，不会把学生改过的密码重置。不能将密码写入命令行参数、代码或日志。私有导入摘要保存在已忽略的 `data/imports/`。

已预开通的学生直接用自己的完整姓名和老师提供的初始密码登录，无需学习码。学生端「账号设置」支持验证当前密码后设置自己的新密码（10–200 个字符）；其他设备的旧会话会失效，成绩和错题继续保留。保留原有学习码流程供后续单独添加或找回账号使用；学生账号也支持中文姓名。

班级卡片的「课程内容」可查看并编辑本科目的课程内容。发布任务时只能选择开设该科目的班级，原有已发布任务与历史成绩不受课程修改影响。科目新增独立的「英语」和「语言学习」，与「学术英语」分开，覆盖本次反馈表中的十种科目。表格未填写的课程内容保持为空，由 master 补充；系统不会把课堂表现当作课程内容。

本轮执行语法检查、Cloudflare 迁移/发布以及导入数量核对，没有新增或运行功能测试。真实学生名单、密码和密码哈希不会提交到 Git。

### 按班级发布

发布弹窗先选择一个班级，再从该班实际开设的科目中选择；未配置课程的班级会提示先配置，不显示无关科目。选择班级时自动勾选全部学生；更换科目只更新场景词汇，保留学生勾选状态，更换班级则显示新班名单并重新默认全选。实际参加人数和已选词汇数会实时更新；没有班级、科目、词汇或参加学生时不能发布。

课程项目从所选班级自动推导；全选时使用整班受众，取消任意学生时发送剩余学生的明确 ID 列表，后端继续校验班级、项目、科目与学生受众。连续 1–30 天发布和考试链接保持可用。此次只执行语法和发布检查，没有运行功能测试。
