# LexiClass · 词间课堂

面向国际预科班级的场景词汇听写应用。教师管理 UNSW 新南预科、NCUK 国际预科、UOW 伍伦贡预科的多个班级；学生通过个人入口填写姓名，完成测试、查看成绩和反复复习错题。

采用可安装的网页应用（PWA）：Windows 和 macOS 电脑使用同一个教学服务，不需要在每台学生电脑上安装 Node.js 或数据库。当前实现为 PWA，不提供原生 `.exe` / `.dmg` 安装包。

界面截图：[教师工作台](docs/screenshots/teacher.png) · [学生学习空间](docs/screenshots/student.png) · [场景听写](docs/screenshots/dictation.png)。截图均使用虚构示例数据。

## 本地运行

需要 **Node.js 24 或更高版本**。应用只使用 Node.js 内置模块，无第三方运行时依赖。

```bash
cd /workspace/vocabulary
npm ci --ignore-scripts
npm start
```

服务默认绑定本机 `127.0.0.1` 的 3000 端口。打开该地址即可进入。点击「体验教师与学生演示」可创建独立的演示空间，示例姓名、班级与成绩均为虚构，和正式教师数据隔离。

正式使用时，在登录页点击「首次部署 · 建立教师账号」。在服务器上私下打开首次启动生成的 `data/setup-key`，输入设置密钥、教师姓名、邮箱、密码和首个班级名称。不要把该密钥或个人学习入口发到公开群，也不要把它们提交到 Git。初始化后此密钥不能再创建账号。

如需自定义配置，将 `.env.example` 复制为 `.env` 后修改。`npm start` / `npm run dev` 自动加载 `.env`；环境变量也可以由服务管理器注入。

## 教师使用流程

1. **创建班级**：选择课程项目，分别建立实际教学班。一个教师账号可以管理三个项目的多个班级。
2. **添加学生**：按班级批量粘贴学生姓名，每行一位。同班同名学生请添加学号以便区分。
3. **分发个人入口**：下载个人入口 CSV，分别私下交给学生。入口凭证保存在链接片段中，不发送给服务器访问日志。学生第一次打开链接后，应用在该设备上记住入口；以后只需姓名。首次没有链接时，也可手动输入老师提供的学习码。
4. **维护词库**：按项目、科目录入英文词、中文释义、英文场景句、对应中文场景和可接受的其他中文答案。也可下载模板后批量导入 UTF-8 CSV，每批最多 300 条。英文场景必须包含英文词，中文场景必须包含中文释义。
5. **发布听写**：选择项目、科目、一个或多个班级，发给全体或指定个人；选择词汇、题型、起止时间和 1–180 分钟答题时长。可按相同本地时间一次排好连续 1–30 天的任务，每天单独计分。
6. **查看成绩**：按项目、班级、科目和姓名筛选，查看姓名、分数、提交时间、超时状态与逐题答案。可导出 CSV。未开始、进行中、未提交和已提交分别显示。

学生不会看到项目选择器、班级选择器或其他同学的名单和成绩。所属项目和班级由老师登记。个人入口同时承担身份凭证的作用；它与普通的“只输姓名即可冒用任何同学”不同。重置某个学生的学习入口，会使旧学习码和该学生当前登录状态失效。

## 题型、计时与错题

- **英译中**：在英文题干内高亮目标词汇，填写中文释义。
- **中译英**：在中文场景内高亮目标词义，填写英文词汇；学生答题接口不会返回英文参考答案。
- **双向翻译**：交替安排以上两种题型。
- **场景选择题**：根据题干选择词义，选项顺序随机；同科目需有至少四个不同释义可供出题。
- **朗读**：英译中和选择题可点击本地系统语音朗读英文场景，仅使用已安装的离线英文语音，不回退到在线服务；未安装时提示老师先配置语音包。

开始后计时不可暂停。个人答题截止取“开始时间 + 答题时长”和任务截止时间的较早者。刷新或重新登录可继续同一份答题记录，不会重新计时。答案在输入后自动保存，界面显示服务器保存状态。

超时时，服务端以**截止前成功保存的答案**评分，未作答计错；超时后补传的答案不会改变成绩。即使关闭页面，服务端也会处理已开始答题的超时提交。尚未开始的任务到期显示未提交，不虚构成绩。提交之后不可修改。

评分为每题等权、折算百分制。匹配时忽略英文大小写、空格及标点，支持老师录入的中文别名；**没有使用 AI 或语义模糊判分**，其他合理译法需提前列入可接受答案。系统不会自动把拼错的词当成正确答案。

答错或空白的词汇自动进入个人错题本，同词同方向不会重复建条目；后续答错会累计错误次数并重新安排复习。先即时巩固，第一次答对后 1 天复习、第二次答对后 3 天复习，连续答对 3 次标记已掌握；答错后 10 分钟可重试。客户端不能通过连续刷新绕过复习间隔。

任务按指定时间开放，学生应用每 30 秒同步一次。桌面提醒须学生授权，并保持应用运行；目前没有应用关闭时的 Web Push、短信或邮件提醒。

## 关闭输入自动纠错

答题框明确设置：

```html
autocomplete="off" autocorrect="off" autocapitalize="off" spellcheck="false"
```

同时请求常见语法扩展不要启用，并在浏览器可取消的英文 `insertReplacementText` 输入事件中阻止自动替换。正常的中文输入法组合输入不被屏蔽。

**这些设置不能强制控制操作系统、第三方输入法或所有浏览器扩展。** 正式课堂请老师统一检查：

- **Windows 11**：设置 → 时间和语言 → 输入，关闭「自动更正拼写错误的单词」及物理键盘文本建议（具体名称随系统语言与版本而异）。Windows 10 对应入口通常在设置 → 设备 → 输入。
- **macOS**：系统设置 → 键盘 → 文本输入 → 编辑，关闭「自动纠正拼写」和行内预测文本；检查英文输入源的文本替换设置。
- **搜狗、QQ 等输入法**：关闭其英文自动纠错、联想补全、自动替换；答英文题建议切换系统英文键盘。
- **浏览器扩展**：在课堂应用中禁用拼写/语法自动替换扩展，或由学校设备管理统一配置。

这是一款课堂练习工具，目前没有锁屏、考试监控或禁止切换其他应用的功能。

## 给 Windows / Mac 学生安装

先将服务部署到学生可访问的 **HTTPS 域名**，再分发个人入口。

- Windows：Chrome 或 Edge → 地址栏安装图标，或菜单中的安装应用入口。
- macOS：Chrome 安装；macOS Sonoma 或更新版本也可使用 Safari → 文件 → 添加到程序坞。
- 每台电脑只安装一个客户端；首次通过个人入口登记后，打开应用即可查看自己的任务。
- PWA 缓存应用外壳，不缓存学生名单、成绩、登录响应或提交请求。**测试、保存、提交和复习需要联网**。

普通局域网 HTTP 可以访问网页，但远端 HTTP 通常无法安装 PWA 或启用系统通知。不要给每台学生电脑独立启动一份服务器，否则学生数据无法集中汇总。

## 正式部署

**中国大陆课堂使用优先采用[国内云服务器部署方案](docs/mainland-deployment.md)**。页面、接口、字体和图标均由学校服务器提供；学生不依赖 GitHub、Google、npm 或境外 CDN。朗读仅使用本地英文语音包。文档附 Nginx、systemd 和自有证书配置，生产部署无需下载 Docker 镜像或 npm 依赖。实际免 VPN 连通性仍需在部署后的中国大陆学校网络验收。

可以直接运行 Node.js，并由学校的 HTTPS 反向代理转发；也提供 Docker Compose + Caddy 配置：

1. 准备服务器与真实域名，将域名 DNS 指向服务器，开放 80/443 端口。
2. 在部署机器的 `.env` 中设置 `APP_DOMAIN=你的真实域名`。
3. 运行 `docker compose up -d --build`。Caddy 会申请证书并转发到应用。
4. 从应用容器的 `/app/data/setup-key` 私下获取首次设置密钥，访问域名创建正式教师账号。
5. 录入实际课程词汇和班级，再分发学生入口。

Compose 默认关闭演示，数据库保存在 `lexiclass_data` 持久卷；应用容器以非 root 用户运行。若自行部署 Node.js，至少设置：

```text
NODE_ENV=production
ALLOW_DEMO=false
HOST=127.0.0.1
PORT=3000
PUBLIC_ORIGIN=https://你的真实域名
DATA_DIR=/受保护的持久数据目录
```

`PUBLIC_ORIGIN` 必须与访问域名一致且无末尾斜杠，用于来源检查及 HTTPS 会话 Cookie。域名配置好之后重新生成学生入口，避免把本地开发地址分发给学生。

当前仅有一个正式教师管理员，管理其所有班级；暂不含多教师角色分工、邮件找回密码或学校 SSO。请妥善保管教师登录信息。此仓库提供部署配置，**不代表已部署到公网**；Docker/Caddy 和真实 Windows/macOS 安装需在目标机器上验收。

## 数据、备份与验证

班级、学生、词库、任务快照、答题记录、错题和会话保存在 `data/lexiclass.sqlite`。密码使用 scrypt 加盐哈希；学习码和会话令牌仅保存哈希。数据目录、备份与入口 CSV 含有个人记录，应由老师或学校管理员保管。不要上传 `data/`。

在线一致性备份：

```bash
npm run backup -- /受保护的备份目录/lexiclass-2026-10-18.sqlite
```

恢复时先停止应用，用备份替换数据目录内的数据库，清理旧的 `lexiclass.sqlite-wal` / `lexiclass.sqlite-shm`，保留访问权限后再启动。请先确认备份可读，且不要覆盖唯一一份现有数据。当前架构采用单 Node.js 实例与 SQLite，适合班级和小型教学中心的初期使用；尚未做大规模并发压测。

```bash
npm test
```

测试使用临时数据库，覆盖身份和班级隔离、定向发布、题目答案保密、自动保存和恢复、评分、错题复习、服务端截止与超时、入口失效、演示隔离、进程重启持久化及输入框设置。`npm run dev` 开启开发热重启。没有需要单独启动的数据库服务、付费 API 或外部凭据。

浏览器交互验证使用开发依赖 Playwright，独立启动临时服务与数据库，结束后清理；无需使用正式学生数据：

```bash
npx playwright install chromium
npm run test:browser
```

若开发机已有 Chromium，可通过 `BROWSER_PATH` 指定其路径；仅在需要的容器环境中设置 `BROWSER_NO_SANDBOX=1`。交互检查覆盖建班、批量学生、个人入口仅输入姓名、连续定向任务、答题框纠错设置与可取消自动替换、刷新恢复、评分、错题复习和窄屏布局。实际执行验证的平台为 Linux Chromium，尚未在真实 Windows/macOS 设备上验收安装。

## 词库来源

内置 31 个**原创场景示例**，覆盖经济、商科、会计、数学、物理、化学、学术英语与计算机。课程项目名称只用于教师分类，示例没有经过学校官方考纲校准，也不是 UNSW、NCUK 或 UOW 的官方词表或真题。正式教学应由老师依据实际教材、授课单元及授权范围导入内容。
