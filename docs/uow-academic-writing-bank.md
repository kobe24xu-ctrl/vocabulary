# UOW 学术写作词库

来源：用户上传的 `12周学术写作词汇表.xlsx`，工作表 `12周词汇表`。
对应现有 UOW `Academic English`（学术英语）科目；不新增项目或科目。

- 原文件 1,176 条周次记录，883 个不同拼写的词汇。
- 按词汇、词性及完整释义去重后保存 1,016 条词条；不同词义分别保留。
- 同一词条可属于多周，保留全部原始周次和序号；第 6、8 周各有两条完全重复记录。
- 保留原释义及词性元数据，以适合场景的主要释义作为答案，其他释义进入可接受答案。
- 每条配自编英文场景句和中文对应句，覆盖论文阅读、文献检索、APA 引用、
  文献管理、改写和论证；明确标注为教学场景，不冒充真实研究或官方试题。
- 填空题、五选一选择题均使用例句，支持英译中、中译英和双向交替。
- 每周词汇学习长期开放，与是否发布考试无关。

UOW 学术英语改用本项目的独立词库，不再读取新南英语或内置通用学术英语示例。
UOW `Language Learning` 继续共用新南英语；数学、计算机、经济的映射保持原配置。
本次只添加新词条并改变可用词库范围，不删除原新南词库、不修改历史试卷快照、成绩、
错题或学生账号。词条保留导入批次与稳定 ID，供后续定位。

原文件及加工数据保存在被 Git 忽略的 `data/uow-writing-import/` 中；正式内容保存于
原 D1，未另建数据库。导入后只读核对 1,016 条及批次；基于实际 D1 内容在本地生成
六种题型/方向组合共 6,096 题，确认场景及五个唯一选项。41 项隔离回归检查通过，
并同步更新原 UOW 共用词库的测试材料以反映学术英语独立后的范围。
