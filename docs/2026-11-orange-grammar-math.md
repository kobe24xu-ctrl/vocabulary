# 赤橙界面、全科词性与新南数学词库

## 界面与答题

采用用户选定的「赤橙班级看板」：白色导航与纸白底色、赤橙操作按钮、按班级分色的考试卡片。教师概览按正在开放、接下来、已经结束排列，原有互动成绩图表保留在可展开区域。学生首页保留待考入口和考试日历；轻柔黑体、字号调节与移动端布局继续可用。

选择题点选即记录答案，200ms 后进入下一题。上一题、下一题和题号导航均可返回修改；答题位置按考试 ID 在当前标签页保存，刷新后继续。所有题目的输入仍保留在同一表单中，切题不会丢失答案。最后统一确认交卷，选择题仍按预设答案判分，不调用 AI。

## 所有科目的词性

给现有 master 词库的所有科目补充 `partOfSpeech` 与 `partOfSpeechNote`，并覆盖内置 31 个教学示例。原词表已有词性时保留来源记录；其余结合例句进行本地语法分析，再针对化学元素、术语、缩写、数学命令与短句复核。元数据记录方法和版本。没有为补充词性消耗 Workers AI 或收费 API 额度；自动分析仍可由教师根据实际授课语境继续修订。

词性及中文用法介绍显示于教师词库、学生长期学习、新发布考试的考前学习和新错题卡片。新增词汇表单及 CSV 导入支持这两个字段。历史试卷与历史错题快照保持原样，不回写词库最新释义，也不向正在答题的接口发送含答案的用法说明。

`scripts/update-vocabulary-grammar.py` 默认预览，显式 `--apply` 后仅修改词性元数据；词汇文本与准备时不一致的记录跳过，防止覆盖并发编辑。原始词表和私有备份保存在忽略提交的 `data/` 目录。

## 新南数学替换范围

来源为用户本次上传的「新南数学按周单词表_两学期.xlsx」：第一学期 12 周 300 词，第二学期 12 周 282 词，共 582 个不同词条。按学期与教学周分组，不展示 lecture 或 tutorial 编号。每词均有词性、用法介绍及自编双语数学题干例句；例句为教学示例，不作为官方试题。填空题和五选项选择题共用这些词条。

原始周次与中文释义保留在来源字段；主释义结合例句消除多义歧义，明确同义表达放入可接受答案，并排除相应同义干扰项。周次筛选、报告标签与自动考试名称都区分两个学期，如 `T1 W01`、`T2 W01`。

`scripts/replace-unsw-mathematics.py` 默认预览，先校验 582 词、24 个分组与两个学期数量。正式写入前备份原数学记录；一次原子 upsert 复用相同词条 ID，新增未有词条，将被替换的旧词条归档。归档词不参与新考试、长期学习和自主模拟；历史试卷快照、成绩与错题引用继续保存。UOW 自有数学词库和 NCUK 数学词库保持原内容。
