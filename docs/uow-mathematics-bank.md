# UOW 独立数学词库

来源为用户上传的 `词汇表.xlsx`，工作表 `词汇表.csv`。
原表 358 条内容记录，覆盖 12 周、35 个单元/主题。

整理后保存 349 条词条。跨周重复词合并分组，并保留原行号、周次、主题和中英原文。
同义词、英美拼写及常用缩写作为可接受答案；斜杠并列的不同概念（如质量/重量、
递增/递减、正相关/负相关）拆分，避免将相反概念设为同义答案。

每条有数学场景英文例句与中文对应句，供每周学习、填空和五选一选择题使用。
场景为教学材料，不声称是官方试题。涉及指数的 product/quotient rule 使用指数法则，
不混用微积分的求导法则。

UOW 数学改用独立词库，不再读取新南数学及内置通用数学样例；新南原词库保留。
学术英语保留此前的独立写作词库，计算机、经济、语言学习保持既有映射。
未更改班级、学生账号、历史试卷快照、错题或成绩。

概率及公式符号标记为 `math-notation`。中译英按符号判分，允许空格与撇号字形差异，
但不去掉括号、补集撇号、交并集或条件符号，因此 `P(A)` 不会被当作 `P(A')`。
一般英文词汇仍使用原来的大小写、标点匹配规则。

加工材料位于 Git 忽略的 `data/uow-math-import/`，正式内容存入原 D1。
只读回取实际入库词条，在本地生成六种题型/方向组合共 2,094 题检查例句和五选项，
并检查补集符号判分；不在生产创建考试。41 项隔离回归检查通过。
