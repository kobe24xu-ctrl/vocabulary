# 班级报告、字号与考试提醒

## 界面

- 正式页面移除五种风格预览入口，保留学院蓝与轻柔黑体。
- 根字号默认18px，登录页和顶部的 A− / A＋ / 还原按钮可在16–26px间调整，同一浏览器刷新后保留。调整仅更新样式，不重建正在输入的答题表单。
- 课程词库必须先选择项目和科目，学生词汇学习直接选择本班科目；选科前不展示混合词汇或周次。周次/Topic选择器仅包含当前科目的分组。
- 学生名单按项目、班级逐层进入；搜索姓名可定位相应班级。

## 可视化成绩

成绩分析默认显示班级入口，再进入科目。科目报告包含跨周趋势、周内考试走势、成绩分布、学生掌握热力图及学生学习卡片。点击图中的点、分数段、周次或学生可联动筛选和回看答卷。

学生画像默认同时显示其各科成绩轨迹，可选择科目、隐藏曲线、对比同场考试班级均分及回看每次答卷。教学概览沿用项目、科目、周次、班级筛选，并改用图表与卡片。平均分只计已交有效答卷，缺考与未交不会被当成零分，未开放考试不计入应交数量。自主模拟仍与正式考试成绩分开。

图表与字体均在本站提供，不依赖外部图表或字体CDN。

## 学生考试提醒

已登录学生通过同源 SSE 接收分配给自己的未交考试。前台页面约每4秒检查一次变化；短连接自动重连，连接异常时使用约8秒的后备检查。登录及重新回到页面时立即读取提醒。顶部红色待考按钮和右上角提醒提供考试入口；未开放考试显示开放时间。只通知该学生所属班级且在指定名单内的考试，不返回题目答案。

提示不要求系统通知权限，不强行打断正在进行的正式考试，也不重建答题表单。页面关闭、休眠或断网时不能即时接收，回到页面联网后恢复。免费套餐原有请求与数据库配额仍适用。

## 个人补考

master在已关闭考试点击「安排补考」，勾选原考试名单中的学生，设置新的开放、截止和答题时长。成绩报告中的缺考学生卡片也提供预选该生的补考入口。

补考使用原考试的题目快照，单独生成考试、受众、答卷和成绩，不覆盖原答卷、原缺考状态或错题。其他学生不能查看或进入该补考。补考通过同一提醒机制显示「个人补考」。迁移0007只新增关联表及索引，不更新账号密码、原考试或成绩；原考试删除后已建立的补考仍保留。

## 本轮隔离检查

虚构师生和临时SQLite检查了：字体18→20并刷新保留、调整字号不丢答案、选科前词汇和分组隐藏、班级名单层级、班级→科目报告、跨科个人轨迹、点图回看试卷、390px移动宽度。未发现浏览器脚本错误。

发布后约4.3秒出现考试提醒，晚登录同样能看到入口；补考只分配指定学生，题目快照与原卷一致，原缺考记录保持不变。未在生产创建验证考试或修改学生成绩。

现有54项测试、浏览器完整答题流程、独立演示浏览器流程及Pages构建通过。原浏览器断言改为读取学生可视化卡片，仍检查同一学生的88分和班级归属。回归中发现并修复其他考试提醒遮住正在作答的提交按钮：正式作答期间只保留顶部提醒，交卷后再显示未读安排。
