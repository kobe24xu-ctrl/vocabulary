# 班级课程、日历排期与成绩概览

## 使用

- NCUK 商科一、二班绑定「商科数学」，工科班绑定「工科数学」。课程仍在班级管理中维护；发布考试和学生学习均遵循该班课程与词库范围。
- 发布时选择班级、科目、词汇周次或 Topic，名称自动生成，例如 `NCUK · 工科数学 · W05`。
- 首场的开放与截止均按北京时间解释。点击日历中的后续日期，按日期先后依次使用下一词汇分组，沿用首场开放时刻和开放窗口；不要求每隔七天。未选中的假期不发布。
- 提交前可在预览中检查和调整每个后续日期的词汇分组。批次最多30场，每场1–100词；分组缺词或超限时阻止整批发布，不默默截断后续周词汇。
- 教师听写任务按班级、科目分层折叠，可全部展开或收起；刷新列表会保持当前折叠状态。
- 教学概览按项目、科目、周次/Topic、班级联动筛选。可点击周次柱形、分数段和班级进一步筛选；点击学生可查看各次考试和逐题作答。
- 平均分只包含已提交且有分数的试卷，保留真实0分。未提交不当作0分。应交数包含预约考试，尚未提交包括待开放、待完成、答题中、逾期未交。
- 新考试保存词汇分组快照；历史考试优先按其词汇ID读取原词库分组，无法识别则单独归入未标注，不按考试日期猜教学周。跨周考试会在涉及的各周显示同一成绩，总体统计不会重复。

## 五种界面选择

`/design-options.html` 提供瑞士排版、学院蓝、纸感教案、冷灰工作台、紫罗兰档案五套可切换页面。均使用虚构示例，不能发布考试，不读取学生数据，无外部字体/CDN。待用户选定后再应用全站视觉；本次只更新功能。

## 数据与兼容

迁移 `0005_ncuk_math_courses.sql` 只更新NCUK词条科目标识和班级课程绑定，保留原词汇ID。商科568词、工科580词。迁移可重复运行；不会写账号、密码、考试、答卷或错题表。旧考试保留原科目，教师列表和概览根据班级当前数学课显示对应归类。

原有显式命名的API客户端仍能创建考试；网页始终传 `autoTitle: true`。Worker、Node和本机演示使用同一命名与时间安排函数。新概览使用本地聚合和原有教师成绩接口，不增加外部分析服务。

## 验证

- `SHARED_BROWSER=1 BROWSER_PATH=/usr/bin/chromium BROWSER_NO_SANDBOX=1 npm test`：包含日历假期、北京时间、分组校验、迁移幂等、数学课程归类、成绩计算与历史周次回退。
- `node test/teacher-tools.mjs`：隔离Node数据库与虚构师生，检查班级科目、自动名称、任意日历日期W05→W07批量发布、展开收起、50分真实提交、周次与分数段筛选、学生和逐题详情。屏蔽第三方页面请求，不操作正式班级。
- 原有 `test:browser` 继续覆盖账号、授权、学生跨设备、限时答题、错题与响应式布局；`test:demo` 覆盖独立演示构建。
- 构建使用 `npm run cf:pages:build` 和 `npm run demo:build`。

正式站检查使用Cloudflare部署状态和D1只读查询，不为验证创建生产考试或改动学生成绩。
