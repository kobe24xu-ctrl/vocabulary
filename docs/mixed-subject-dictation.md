# 多科目混合听写与随机抽词

发布入口仍先选班级。勾选「多科目混合听写」后，可以选中本班多门课程，并为每门课程独立勾选一个或多个周次、Topic 或单元；「全部范围」与具体分组互斥。只有已绑定给该班的科目可用。

「随机考察词数」设置整场总量，支持 1–100 词，例如 50。候选范围合并后按词条 ID 去重；同一词条被多个周次或共用课程引用时只考一次。候选词池仍可手动排除个别词汇，候选不足时阻止发布并显示数量。各科题量不固定，随机抽取范围为合并词池，不设各科配额。

服务器在发布时使用加密随机数和部分 Fisher–Yates 抽样，均匀抽取不重复词条并固定为试卷快照。学生开始、刷新、续考不会重新抽题，同一任务的学生使用同一份试卷。每题保留所属科目、所选分组、词性、例句与评分信息；五个选项优先从本题所属科目的词库生成。选择题继续按预设答案评分，不调用 AI。

成绩分析可拆出混合试卷中各科的正确题数与得分；班级整体统计合并各科切片后计算整场成绩，不重复计算交卷人数和场次。错题仍按每题所属科目收录，共用 UOW 英语词库继续使用既有的课程区分规则。考试列表可从相关科目或「多科目综合」找到混合任务，学生入口、提醒与日历显示综合任务。

单科模式保留原来的按后续日期递进教学周的日历安排。多科目模式的后续日期沿用各科当前选定范围，每场独立随机抽词，发布页明确提示；改换各科范围可另发任务。

`0008_task_selection.sql` 仅给任务增加 `selection` JSON 元数据列，默认 `{}`。旧试卷、成绩、账号密码与错题保持原样；补考复制原卷及其范围，不重新抽题。Node 启动执行等价的幂等列检查，Cloudflare 通过既有迁移命令应用。Node、Worker 和独立演示复用同一个范围校验与抽样模块。

本轮完成语法检查、Pages 与独立演示构建，并渲染桌面和 390px 手机布局。未新增或手动运行测试，也未在生产创建验证考试或学生答卷。生产发布状态通过 Cloudflare 项目与域名元数据核对；当前环境未放行正式域名的直接 HTTP 访问。
