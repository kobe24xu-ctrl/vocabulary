# 直接选择班级、科目与学生考试日历

## 老师界面

- 「班级管理」「学生名单」合并成一个「班级与学生」入口。先选班级，进入后可统一添加或导出学生、管理课程、查看学生画像和处理账号。班级课程标签可直接点开内容。
- 班级详情、听写任务、成绩分析、词库与学生词汇学习均提供明确的返回按钮。听写任务按班级→科目→考试逐层进入，考试列表可收起；返回科目与班级时清除不适用的搜索条件。
- 项目、班级、科目使用直接点击的卡片或按钮，涵盖教学概览、词库、发布听写、添加学生和自主模拟。周次、题型、翻译方向等其他设置保留原有控件。
- 原生选择控件仅保留作表单值来源，按钮同步触发既有的课程联动逻辑；必填内容缺失时显示错误并将焦点移到可点击的选项。选择状态通过aria-pressed标记，键盘可直接操作。
- 经济、商务、会计、商科数学、工科数学、物理、化学、英语、学术英语和计算机使用相应图标。
- 班级采用不同的柔和底色与强调色，名单卡片、任务、成绩报告及该班学生首页和日历使用同一色系。颜色由现有班级ID排序得出，登录接口只返回本班色号，不额外暴露其他班级。班级名称与图标仍保留，不单靠颜色区分。

## 学生考试日历

「我的学习」首页显示月历，标记老师发布给本人的考试。日期、月份切换、开放及截止时刻均按北京时间计算；点击日期查看当天安排，点击考试进入说明页，确认开始才计时。未来考试显示「查看考试安排」，不会提前开放答题。已完成考试可回看成绩，补考显示个人补考标记。

今日没有新开考试时，侧栏列出本月待考及当前仍开放的考试。月历与既有考试提醒同步，新考试出现后无需手动刷新；未分配给本人的任务不会出现在日历中。日历不改动正式答卷、成绩或学生密码。
