# 老师端导出单词

入口：master 登录 → 课程词库 → 导出单词 → 选择项目和科目 → 下载 Excel。

导出包括该科目的全部已录入、未归档词条，不受当前搜索、周次筛选和页面显示60条的限制。内置示例排除，项目间共用词库沿用现有词库规则，并保留词条实际来源项目与科目。没有词汇的范围不生成空文件。

Excel 为真正的 `.xlsx`，在已登录的浏览器中生成并下载，不需要额外云盘、公开链接或服务。文件名包含项目、中文科目和北京时间日期，例如 `NCUK_英语_词库_2026-11-09.xlsx`。

工作表包含：

- 导出说明：导出范围、记录数、不同词形数、按周展开数量及每组数量。
- 词库总表：英文、中文、词性与用法、双语例句、周次 / Topic、答案别名、说明、来源文件、来源项目和词条 ID。
- 按周词表：按原始分组展开，方便筛选、学习和打印；跨周记录会重复出现。
- 完整JSON：保留每条原始词库记录的全部字段。超长原始 JSON 按词条 ID 和分段序号存储，可拼接还原。

数据从现有教师专属 `/api/words` 接口重新读取，该接口继续按当前登录教师过滤所属词条，未登录返回401、学生返回403。按钮仅在老师端显示。生成文件不读取学生名单、密码、学习码、考试或成绩，不改变任何数据库记录。单元格使用显式字符串而非公式，避免词汇文本被作为 Excel 公式执行。

实现使用标准 OOXML 和 ZIP，无新增依赖，不把词库发送至外部生成服务。手机布局沿用现有响应式选择控件，下载链接短暂附加到文档以支持不同浏览器，Blob URL 延后释放。

验证：`npm test`；`node test/vocabulary-export-browser.mjs`（需要 Chromium 与 Python openpyxl）。浏览器测试默认使用虚构的80条词汇；可用 `EXPORT_FIXTURE_FILE` 指向私有只读导出记录，在临时数据库中复现真实词库下载。测试覆盖跨科目切换、完整数量、中文文件名、ZIP CRC、Excel逐字段还原、手机保存、权限隔离和导出前后数据不变。私有词表和下载产物保存在忽略提交的 `data/`、`dist/` 中。
