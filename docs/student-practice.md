# 学生自主模拟与学院蓝界面

## 已接受的要求

全站采用学院蓝配色与完整霞鹜新晰黑（用户选择的02轻柔黑体）。字体同源提供，不要求Windows/macOS预装字体，也不依赖Google字体服务。正式版本使用完整字体，支持词汇、姓名和课程内容；此前的精简字体只用于固定样张。

学生在「自主模拟」选择自己班级开设的科目和已有周次/Topic，即可自己开始模拟考试。无需老师发布、不依赖任务名单、任务名称或考试日历；不设练习次数限制。

- 范围为所选科目、周次的整组词汇；不默默抽掉部分词汇。
- 支持五选一、填空，以及英译中、中译英、双向翻译。
- 可设置1–180分钟模拟时长，自动保存，刷新或换设备后可继续；时长由服务端时间决定。
- 可立即再练同一周，也可返回设置，选择其他周次/科目。开始新练习时，旧的未交卷模拟标记为已结束，不计入均分。
- 模拟成绩、用时、逐题作答、练习错词独立保存。历史记录分页读取；模拟结果不计入老师的正式考试成绩。
- 可勾选「只练本周的模拟错词」巩固；同一翻译方向再答对后，该项从待巩固列表移出。
- 单场支持1–300个词汇；超过容量时提示选择更细的周次/单元，不切断词库。没有词汇的假期、考试周不凭空补词。

## 出题与判分

`lib/practice-questions.mjs` 打乱词序，采用多个复习提问模板重新组织题干，保持原始学科场景中的事实、数字、公式及双语释义不变。不会为了变化而虚构科学或数学结论。与上一次练习比较，避免直接重复同一词汇的同向题面；选择题优先替换干扰项，在候选不足时调整选项顺序。生成题目不调用AI；无限次练习不依赖生成额度。

填空判分沿用现有语义判分设置和标准答案后备机制；选择题、数学符号仍使用确定性判分。Workers AI Free的每日额度与平台限制继续适用；不启用付费服务。Node本地和本机演示使用标准答案判分。

## 数据与访问

新增迁移 `0006_student_practice.sql` 仅建立独立 `practice_attempts`、`practice_mistakes` 表及索引，不修改账号密码、老师考试、正式答卷、正式错题。删除学生时，其模拟记录随账号级联删除。所有模拟接口按当前登录学生ID限制访问。

- `GET /api/practice`：自己的模拟列表、累计统计、待巩固错词；支持before分页。
- `POST /api/practice`：`subject`, `wordGroup`, `mode`, `questionType`, `duration`, 可选 `mistakesOnly`。项目和词汇从服务端根据班级读取，不接受客户端任意词汇或成绩。
- `GET /api/practice/:id`：自己的模拟与未交卷公共题目；交卷前不返回标准答案或可接受答案。
- `PATCH /api/practice/:id`：自动保存答案。
- `POST /api/practice/:id/submit`：交卷、评分并整理独立练习错词。

Node和D1使用相同服务；D1单次评分使用固定数量的批量SQL，而非每词一次查询。并发评分令牌、原子写入和已提交状态保证重复交卷不会重复累加错词。学生对其他人的记录只会得到404。
