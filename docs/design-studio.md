# 五套独立设计样稿

入口：`/design-studio.html`。每套都能切换老师、学生视角，也可通过 `?style=cloud&role=student` 直接访问。

| 编号 | style | 方向         | 布局重点                                   |
| ---- | ----- | ------------ | ------------------------------------------ |
| 01   | cloud | 云白工作台   | 白色导航、当前考试、连续班级列表与周考程   |
| 02   | folio | 纸页学院     | 横向导航、淡紫教学手册、题干例句与页边月历 |
| 03   | sky   | 晴空日历     | 月历为首页主体，选中日期连接当天考试入口   |
| 04   | night | 夜航数据台   | 石墨深色、教学周曲线、班级对比与考程       |
| 05   | board | 赤橙班级看板 | 班级分色，按今天、接下来、已完成组织考试   |

遵循用户指定的 `frontend-design`。当前环境未安装该技能，检索本地及技能目录后，读取并采用其公开原版：<https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md>。先形成色彩、字体、布局与原则方案，再检查是否套用通用模板；将纸页方案调整为淡紫教案、深色方案调整为蓝灰石墨，各方案采用不同首页结构。通过实际浏览器渲染回看字号、间距、对比度与小屏布局。

样稿使用虚构班级记录及示例题，不加载生产账号、学生名单或成绩，不调用任何 `/api/` 接口。发布听写仅添加到当前样稿的浏览器内存，刷新恢复；选择风格只将选择记在本机localStorage。正式网站首页、应用样式、教师入口和数据库保持原状，待用户选择后再实施正式改版。

可体验：班级→课程、词库科目与周次/Topic选择、按月翻考试日历、点击成绩曲线、在样稿中安排听写、进入三道五选一示例题并查看样稿分数。商务和经济按Topic展示，其余科目按周展示。

图库中的五张PNG直接截取各方案的浏览器首页，图片与交互页面对应。中文继续使用本站完整轻柔黑体，英文词汇采用系统衬线字；无外部字体、图表或图片CDN。字体许可沿用本站字体许可页。
